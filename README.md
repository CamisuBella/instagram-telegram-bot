# Instagram Telegram Bot

Täglicher Report über neue Posts von 3 Instagram-Accounts, gesendet via Telegram.

## Accounts
- @taliamenzel
- @tina_schwarz.lipoedem_talk
- @lipoedemkeinproblem

## Setup
1. `.env` Datei anlegen (siehe `.env.example`)
2. `pip install -r requirements.txt`
3. `python3 bot.py`
